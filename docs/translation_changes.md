## 1b. Chapters 7 onward, checked against the Japanese disc

The Japanese text here was decoded directly from your Japanese disc 1 (99.75% of characters decoded) and paired box-for-box with the PW text. Bilingual reviewers went through 566 field files in 26 batches. I then checked every proposal mechanically: the old text occurs exactly once, it fits the box, and it applies to the shipped bytes. I also read each one against its Japanese line. Accepted: **455 edits in 198 files**, of which 320 are mistranslations, 37 omissions, 9 speaker fixes, 69 typos and 20 style fixes.

Not accepted:
- A speaker name that the first pass had already added (1204#81).
- A rewording of a line that was already correct (1934#6).
- Removing the cut-off second line of the 1696 "Received" box, which may be deliberate engine data.
- Two 1258#15 fixes whose text differs between the `.txt` and the shipped disc.

Fixes were copied to byte-identical boxes in other files only when the text is distinctive. Short boxes like "..." recur with different speakers, and identical boxes in one file can carry different Japanese (1068#10 vs #16).

**Policy calls to know about:** Zephyr's age follows the JP (522, not 513). Rico is a three-time champion everywhere. The jump tutorial no longer names buttons, because the US release swaps the JP layout.

## How it was verified

- **Encoder:** 16,535 shipped text blocks re-encode byte for byte. Edits are byte-level replacements inside the original blocks, so opcodes the `.txt` dump never exported are preserved.
- **Field files:** in each of the 76, only the edited blocks differ. The other 8 sections are byte-identical, and each rebuilt text section decodes back exactly.
- **Sector level:** every changed sector belongs to an intended file or the file table (disc 1: 82 files; disc 2: 28 files).
- **Relocation:** two disc-1 field files grew past their original sectors and were moved to the end of the image (+269 KB).
- **Second pass:** in the v2 images, every changed sector belongs to an edited file or the file table. Disc 1 has 198 files and 657 sectors; disc 2 has 51 files and 176 sectors. Each disc-2 target was found by content: same block count, at least 90% byte-identical blocks, and the edited block itself identical. Sampled EDC/ECC (about 10,600 sectors) is all valid.
- **v3:** disc 1 has 5 more files (23 sectors) and disc 2 has 21 (78 sectors), with no stray sectors and valid EDC/ECC. Each synced disc-2 file was checked to be byte-identical to its disc-1 twin.
- **Not verified:** none of this has been booted on an emulator or hardware.
